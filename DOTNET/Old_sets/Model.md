## Section A

**Attempt any TWO questions.**

1. What is the difference between abstract class, interface, and sealed class? When would you use each? Write a program demonstrating the use of abstract class with abstract methods and sealed class to prevent inheritance.

2. What are different Action Result Types in ASP.NET Core MVC? Explain with examples. Design an API Controller that returns JSON response for a Product entity (ProductId, Name, Price, Category) with GET, POST, PUT, and DELETE operations.

3. Differentiate between .NET, .NET Core, and Mono frameworks. Explain the compilation and execution process of .NET applications covering CLI, MSIL, and CLR. Discuss different hosting models for ASP.NET Core applications: IIS, Nginx, Kestrel, and Docker containerization.
