## Study Priority Summary

1. **Master first:** COCOMO ([[SE/Syllabus#Unit 10. Software Management (7 Hrs.)\|Unit 10]] — practice numericals for organic/semidetached/embedded), Process Models (waterfall/spiral/V-shape/incremental — [[SE/Syllabus#Unit 2. Software Processes (5 Hrs.)\|Unit 2]]), Software Maintenance & Evolution ([[SE/Syllabus#Unit 9. Software Evolution (3 Hrs.)\|Unit 9]]), SCM ([[SE/Syllabus#Unit 10. Software Management (7 Hrs.)\|Unit 10]]), Agile Development ([[SE/Syllabus#Unit 3. Agile Software Development (3 Hrs.)\|Unit 3]]), Requirements Engineering ([[SE/Syllabus#Unit 4. Requirements Engineering (3 Hrs.)\|Unit 4]]), Architectural Design patterns ([[SE/Syllabus#Unit 6. Architectural Design (6 Hrs.)\|Unit 6]]), UML diagrams (use case/class/sequence — [[SE/Syllabus#Unit 5. System Modeling (6 Hrs.)\|Unit 5]]).
2. **Then cover:** Verification vs Validation & testing types ([[SE/Syllabus#Unit 8. Software Testing (5 Hrs.)\|Unit 8]]), Functional/Non-functional requirements (Unit 4), Behavioral/Structural models (Unit 5), Quality Assurance/Management (Unit 10), Prototyping models (Unit 2), Risk Management (Unit 10).
3. **Last, if time remains:** Design patterns/OO UML design (Unit 7), path testing, cleanroom development, formal/interface specification, MDA, open-source development, incremental vs integration & configuration models.

> Note: Diagram-based questions (use case, class, sequence, context) and numerical COCOMO problems show up almost every year — practice drawing diagrams for new hypothetical systems and solving COCOMO for different KLOC/modes, not just memorizing definitions.
